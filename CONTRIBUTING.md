# Contributing

Glad you're here. For now, Resume Bar does not accept pull requests or feature requests: it is a personal project, and I would rather keep it small than let your work sit unanswered.

- **Bugs:** open an issue with your macOS version, the steps and what happened. I read them when time permits, and I can't promise a reply or a fix.
- **Security problems:** please follow [SECURITY.md](SECURITY.md) and don't open a public issue.
- **Your own version:** the license allows it. Fork it and make it yours. Please give it a different name and icon; see [TRADEMARKS.md](TRADEMARKS.md).

To build and test, see the readme. The code is Apache-2.0, and anything accepted in the future would be under the same license.
